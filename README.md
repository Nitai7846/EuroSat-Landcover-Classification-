This repository explores the EuroSAT dataset, which comprises 27,000 multispectral satellite images spanning 10 distinct land use and land cover classes, including Forest, Annual Crop, and Residential. Captured by Sentinel-2, the dataset leverages 13 spectral bands ranging from visible light (RGB) to near-infrared and shortwave infrared, offering rich spatial and spectral details. We conducted experiments comparing machine learning and deep learning approaches for classification. A baseline Random Forest model achieved an accuracy of 79.69%, while a convolutional neural network (CNN) outperformed it with a test accuracy of 86.46%, effectively leveraging spatial and spectral patterns. Further analysis demonstrated the added predictive value of multispectral data over traditional RGB imagery, confirming the significance of using all available bands for enhanced accuracy. These results highlight the utility of the EuroSAT dataset and the potential of deep learning for advancing land-use classification tasks.
